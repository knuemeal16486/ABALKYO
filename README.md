# 마음 정원 (Mind Garden)

초등학교 교실에서 사용하는 **감정 기록 그림일기** 앱입니다.
학생이 매일의 감정을 솔직하게 기록하면, 그 마음을 거름 삼아 화면 속 나만의 식물이 단계별로 자라납니다. 사회·정서 학습(SEL)을 자연스럽게 돕도록 설계되었습니다.

## 교육적 의도

- **모든 감정은 소중하다**: 기쁨·신남·평온·고마움뿐 아니라 슬픔·불안·화남·우울도 똑같이 식물을 자라게 합니다. 어려운 감정을 고르면 따뜻한 비가 내려 식물을 보살피는 연출로, "힘든 마음도 나를 키운다"는 메시지를 전합니다.
- **꾸준함의 보상**: 기록을 거듭할수록 씨앗 → 새싹 → 성장 → 개화 → 결실로 식물이 자라고, 다 키우면 정원 도감에 보관한 뒤 새 씨앗을 심습니다. 한 학기에 걸친 꾸준한 정서 기록 습관을 유도합니다.
- **돌아보기**: 마음 달력에서 연속 기록일, 전체 기록 수, 최근 30일 감정 분포를 한눈에 보며 자신의 마음을 돌아봅니다.

## 주요 기능

- 8가지 감정 선택, 사진 한 장 첨부(선택), 자유 일기 작성
- 날짜별로 바뀌는 글감 프롬프트로 쓸 거리 안내
- 식물 4종(사과나무 · 해바라기 · 다육식물 · 고사리)을 직접 그린 절차적 애니메이션으로 표현, 사과나무는 한국 기후 기반 사계절 변화 반영
- 시간대별 하늘 색감, 감정에 따른 비 연출 등 힐링 비주얼
- 마음 달력 + 통계 요약, 일기 삭제
- 정원 도감(다 키운 식물 보관)
- 공유 태블릿을 위한 "새로 시작하기(초기화)" 기능

## AI 기능 (Gemini 활용)

이 앱은 **AI로 교사가 아동을 더 잘 이해할 수 있는 방법**을 보여주는 시연/연구용 프로토타입입니다.

- **AI 그림일기 (아동용)**: 일기를 제출하면 Gemini가 아이의 하루를 따뜻한 그림일기 글과 공감 답글로 들려주고, 가능한 경우 분위기에 맞는 그림을 생성합니다(이미지 생성 실패 시 글로 폴백).
- **마음 리포트 (교사용)**: 최근 감정 일기를 AI가 종합해 ▲정서 요약 ▲감정 패턴·변화 ▲자주 등장한 주제 ▲교사를 위한 대화 제안을 한 화면에 정리합니다. "진단이 아닌 참고용" 캐비엇을 항상 표시합니다.

AI 기능은 교사가 **설정 → 교사용 AI 설정**에서 Gemini API 키를 입력해야 켜집니다(키 없으면 자동 비활성, 완전 오프라인 동작).

> Gemini API 키는 [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급할 수 있습니다.

## 개인정보 및 데이터 처리

- **저장**: 모든 일기·사진·통계·API 키는 **기기 내부에만** 저장됩니다. 자체 서버는 없습니다.
- **AI 사용 시**: AI 기능을 켜고 사용할 때에 한해, 해당 일기 텍스트(및 그림 생성용 프롬프트)가 처리를 위해 **Google Gemini API로 전송**됩니다. 아동의 사진 원본은 그림 생성에 전송하지 않습니다.
- **열람 범위**: 본 프로토타입은 시연/연구 목적이며, 아동의 기록은 기기를 관리하는 **담임교사**가 열람하는 것을 전제로 합니다. 실제 교실 운영 시에는 보호자 동의 등 관련 지침(개인정보보호법·교육기관 방침)을 반드시 확인하세요.
- **권한**: AI 호출을 위한 인터넷 권한만 사용합니다. 위치 권한은 사용하지 않으며, 사진은 시스템 사진 선택기로 가져오므로 별도 저장소 권한이 필요 없습니다(Android 13+).

## 대상 환경

- Android 태블릿 (세로 화면 고정)
- Flutter 3.41+ / Dart 3.11+

## 빌드 및 설치

```bash
# 의존성 설치
flutter pub get

# 분석 & 테스트
flutter analyze
flutter test

# 디버그 실행 (연결된 기기/에뮬레이터)

flutter build apk --release
```

> 현재 릴리스 빌드는 디버그 서명키로 서명됩니다. 사내 배포(MDM)나 사이드로딩에는 충분하지만, 정식 배포 시에는 `android/app/build.gradle.kts`에 별도 서명 설정을 추가하세요.

## 교실 운영 팁

- 학생 1인 1기기라면 처음 한 번만 이름과 씨앗을 정하면 됩니다.
- 여러 학생이 한 태블릿을 돌아가며 쓴다면, 다음 학생 차례에 **설정 → 새로 시작하기**로 초기화하세요.
- 매일 같은 시간(예: 아침 활동, 종례 전 5분)에 기록하면 연속 기록일이 쌓이며 동기 부여가 됩니다.
